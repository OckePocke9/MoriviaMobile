# Morivia branding

- App name: Morivia. Android release ID: com.morivia.app; debug ID: com.morivia.app.debug.
- Launcher icon: purple, blue and cyan Morivia symbol on black.
- In-app and README wordmarks: transparent background.
- Nuvio provider sign-in logo and authentication copy: preserved.
- Legal attribution and third-party service identities: preserved.
- Original source namespaces, storage keys, JNI identifiers, OAuth redirect schemes and service endpoints remain compatible. These are implementation contracts, not Morivia display branding.
- Updates target this repository, never the upstream APK.

The logo asset was extracted from the supplied Morivia reference using the built-in image editor, then resized for each platform resource. Prompt: isolate the original gradient ribbon symbol; remove screenshot, black tile and text; preserve silhouette, folds and triangular cutout on transparency.
