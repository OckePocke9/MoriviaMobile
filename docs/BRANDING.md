# Morivia branding

- App name: **Morivia** on Android and iOS.
- Android app ID and iOS bundle ID: `com.morivia.app`.
- Launcher and home screen icon: the purple, blue and cyan Morivia symbol on black.
- In-app and GitHub artwork: transparent backgrounds. Source files are in `assets/branding/`; the Android icons are in the app modules and the iOS icons in `iosApp/iosApp/Assets.xcassets`.
- Nuvio account sign-in keeps Nuvio's own name and logo, because it is Nuvio's service.
- Internal code names (`com.nuvio.app` package, `nuvio://` links, `NUVIO_*` settings) are technical and stay unchanged; see [AGENTS.md](../AGENTS.md).
- The original authors' copyright and the GPL-3.0 license are kept.
